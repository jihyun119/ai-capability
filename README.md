# POOKIE — AI 활용 역량 진단 서비스

> AI 활용의 기준이 모호한 시대, 사용자의 AI 활용 방식과 실전 역량을 진단하고 다음 성장 방향을 제시하는 서비스.

[서비스 체험하기](https://ai-capability-green.vercel.app/) · [GitHub 저장소](https://github.com/jihyun119/ai-capability)

POOKIE는 사용자의 **AI 활용 태도, 활용 역량, 실무 적용**을 단계적으로 분석하는 웹 기반 AI 역량 진단 서비스입니다.

가볍게 참여할 수 있는 AI 관계 유형 테스트부터, 업무 상황에서의 활용 방식 분석, 직무별 인앱 채팅 기반 실전 평가까지 총 3개의 Track으로 구성되어 있습니다.

진단 결과를 통해 현재의 상태 및 강점과 보완점을 확인하고, AI를 더 효과적으로 활용하기 위한 구체적인 개선 방향을 제안받을 수 있습니다.

---

## 1. 서비스 배경

생성형 AI의 등장으로 ChatGPT, Claude 등의 도구는 이미 일상이 되었습니다. 취업 준비, 과제, 업무 보고서까지 AI를 쓰지 않는 사람을 찾기가 더 어렵고, 기업들은 이미 AI 활용 역량을 채용 기준으로 보기 시작했습니다. 하지만 AI를 자주 사용하는 것만으로 실제 활용 역량을 설명하기는 어렵습니다.

어떻게, 얼마나 더 AI를 활용할 수 있는지에 대한 기준이 명확하지 않은 지금 시점, 자신의 AI 활용 방식을 객관적으로 파악하기 위해 이 서비스를 기획하게 되었습니다.

POOKIE는 다음 세가지에 집중했습니다.

- 자신의 AI 활용 방식을 재미있고 직관적으로 파악할 수 있게 한다
- 자신의 AI 활용 능력을 객관적인 지표로 확인할 수 있게 한다
- AI 활용 능력을 강화하는 학습 도구로서 발전한다

단순 사용 빈도가 아니라 **목표 설정, 맥락 제공, 결과 검토, 반복 개선, 의사결정 개입**과 같은 행동을 기준으로 사용자의 AI 활용 방식을 보여주는 것이 서비스의 핵심입니다.

## 2. 서비스 구조

사용자는 원하는 Track부터 시작할 수 있으며, Track 1에서 Track 3으로 갈수록 평가 깊이와 난이도가 높아집니다.

| Track | 진단명 | 주요 방식 | 결과 |
|---|---|---|---|
| Track 1 | AI 관계 유형 테스트 | 12문항 객관식 + 외부 LLM 분석 JSON | 4개 관계 축과 16가지 캐릭터 유형 |
| Track 2 | AI 활용 역량 테스트 | 행동 기반 객관식 6문항 + 외부 LLM 분석문 | 6개 역량 축, 100점, 유형 및 피드백 |
| Track 3 | AI 실무 적용 테스트 | 직무별 시나리오에서 최대 5턴 인앱 채팅 | 8개 평가 축, 종합 점수, 강점·약점·개선 제안 |

## 3. Track별 구현 내용

### Track 1. AI 관계 유형 테스트

사용자가 AI를 대하는 관계적 태도를 가볍게 진단합니다.

**1. Track 구성**

- AI 활용 방식을 자가진단하는 객관식 12문항
- 평소 사용하는 외부 LLM을 통한 상호작용 습관 분석
- 다음 4개 진단축을 기반으로 한 16가지 관계 유형 도출

| 진단축 | 진단 내용 |
|---|---|
| 의존도 | 일상생활 및 업무 시 AI에의 의존 수준 |
| 친밀도 | AI를 정서적·관계적으로 대하는 정도 |
| 신뢰도 | AI의 판단과 결과를 수용하는 정도 |
| 통제욕구 | AI에게 목표·조건·형식을 지정하고 작업 과정에 직접 개입하는 정도 |

**2. 진단 방식**

1. 사용자가 객관식 12문항에 응답합니다.
2. 제공된 진단 프롬프트를 평소 사용하는 ChatGPT, Claude 등의 외부 LLM에 입력합니다.
3. 외부 LLM이 사용자의 상호작용 습관을 분석해 signals, confidence, notes, evidence_mode가 포함된 JSON을 반환합니다.
4. 사용자는 반환된 JSON을 POOKIE에 붙여넣습니다.
5. 백엔드는 잘못된 JSON 구조를 로컬 규칙으로 복구하고 입력값을 검증합니다.
6. 객관식 점수 70%와 외부 LLM 분석 점수 30%를 결합해 축별 점수를 계산합니다.

**3. 결과**

| 결과 유형 | 한 줄 요약 |
|---|---|
| AI 몰라형 | AI 활용 빈도와 신뢰 수준이 모두 낮으며, AI와 일정한 거리를 유지하는 유형. |
| 시키는만큼만 해 형 | AI를 자주 활용하거나 신뢰하지는 않지만, 필요한 경우 작업의 조건과 방향을 직접 통제하는 유형. |
| 프로 검색러형 | 필요한 경우에만 AI를 활용하며, 결과를 비교적 신뢰하고 작업 과정은 AI에 맡기는 유형. |
| 냉철한 조련사형 | AI를 필요할 때 실용적으로 활용하며, 결과를 신뢰하되 조건과 방향은 직접 설정하는 유형. |
| 가벼운 수다쟁이형 | AI 활용 빈도와 결과에 대한 신뢰는 낮지만, 대화 과정에서는 정서적 친밀감을 형성하는 유형. |
| 의심많은 단골형 | AI를 친근하게 대하지만 결과는 신중하게 검토하며, 작업의 주도권을 직접 유지하는 유형. |
| 필찾하는 친구형 | 필요한 경우 AI를 친근하게 활용하며, 결과를 신뢰하고 작업 과정은 AI에 맡기는 유형. |
| 따뜻한 완벽주의자형 | AI와 친밀하게 상호작용하고 결과를 신뢰하면서도, 작업의 조건과 방향은 직접 관리하는 유형. |
| 불안한 상습의뢰인형 | AI를 자주 활용하지만 정서적 거리와 낮은 신뢰를 유지하며, 작업 과정에는 적극적으로 개입하지 않는 유형. |
| 프로 트집러형 | AI를 자주 활용하지만 결과를 쉽게 신뢰하지 않으며, 지속적인 검토와 수정을 통해 작업을 주도하는 유형. |
| 드라이한 비즈니스맨형 | AI를 자주 활용하고 결과를 신뢰하지만, 정서적 교류나 작업 과정에 대한 개입은 최소화하는 유형. |
| 선긋는 상사형 | AI를 자주 활용하고 결과를 신뢰하면서도, 정서적 거리를 유지하며 작업의 방향을 직접 통제하는 유형. |
| 감정 쓰레기통형 | AI를 자주 사용하고 정서적으로 친밀하게 대하지만, 결과에 대한 신뢰와 작업 개입 수준은 낮은 유형. |
| 애정 넘치는 경계형 | AI와 친밀하게 상호작용하지만 결과는 신중하게 검토하며, 작업의 주도권을 직접 유지하는 유형. |
| 든든한 파트너형 | AI를 자주 사용하고 정서적으로 친밀하게 대하며, 결과를 신뢰하고 작업 과정은 AI에 맡기는 유형. |
| 집착하는 애인형 | AI를 자주 사용하고 친밀감과 신뢰를 형성하면서도, 작업의 전 과정과 방향을 직접 통제하는 유형. |

- 4개 축 점수 및 UI 레벨
- 16가지 AI 관계 유형 중 1개
- 유형명, 설명, 핵심 키워드
- 유형 산출 근거
- 분석 근거 수준 안내
- 결과 이미지 저장 및 공유

### Track 2. AI 활용 역량 테스트

전문적인 작업에서 사용자가 AI를 얼마나 구조적으로 활용하는지 분석합니다.

**1. Track 구성**

- 행동 기반 객관식 6문항
- 사용자의 과거 AI 상호작용 습관을 설명하는 외부 LLM 분석문
- 다음 6개 평가축을 기반으로 한 점수 도출

| 평가축 | 만점 |
|---|---:|
| 작업 명확성 | 20점 |
| 배경·맥락 | 20점 |
| 역할 지정 | 15점 |
| 출력 형식 | 15점 |
| 반복 개선 | 15점 |
| 비판적 검토 | 15점 |

**2. 진단 방식**

1. 사용자가 객관식 6문항에 응답합니다.
2. 제공된 진단 프롬프트를 평소 사용하는 ChatGPT, Claude 등의 외부 LLM에 입력합니다.
3. 외부 LLM이 사용자의 과거 AI 상호작용 습관을 분석한 분석문을 반환합니다.
4. 사용자는 반환된 분석문을 POOKIE에 붙여넣습니다.
5. 백엔드는 객관식 6문항의 응답 여부와 붙여넣은 분석문을 검증합니다.
6. 객관식 점수 40%와 외부 LLM 분석 점수 60%를 결합하고, 객관식 구조에 따른 점수 편차를 보정해 최종 점수를 계산합니다.
7. 최종 점수를 기준으로 AI 활용 유형을 결정하고, 강점과 보완점 및 AI 활용 스타일을 생성합니다.

**3. 결과**

| 유형 | 점수 구간 |
|---|---|
| AI 파트너형 | 85점 이상 |
| AI 활용형 | 70점 이상 85점 미만 |
| AI 탐색형 | 55점 이상 70점 미만 |
| AI 입문형 | 40점 이상 55점 미만 |
| AI 초보형 | 40점 미만 |

- 100점 만점 종합 점수
- 6개 축 레이더 차트
- 점수 구간별 상대 위치 표시
- 강점과 보완점
- AI 활용 스타일 요약
- 결과 이미지 저장 및 공유

### Track 3. AI 실무 적용 테스트

가상의 직무 상황에서 사용자가 AI와 직접 대화하며 실제 결과물을 만드는 과정을 평가합니다.

**1. Track 구성**

- 실제 업무와 유사한 3개의 직무별 시나리오

| 분야 | 시나리오 |
|---|---|
| PM | 분기 핵심 기능 우선순위 결정 |
| 마케팅 | 신제품 재구매율 개선 캠페인 |
| 데이터 분석 | 사업 성과 변화 분석 프로젝트 |

- AI와 협업할 수 있는 최대 5턴의 인앱 채팅
- 대화에 따라 누적·수정되는 실무 산출물
- 다음 8개 평가축을 기반으로 한 점수 도출

| 평가축 | 근거 |
|---|---|
| 목표 정의 능력 | 수행해야 할 과업의 목적과 기대 결과를 구체적으로 명시하는가 |
| 맥락 제공 능력 | 과업 수행에 필요한 배경정보, 참고자료 및 제약조건을 충분히 제공하는가 |
| 정보 구조화 능력 | 지시사항과 본문을 구분하고, 내용을 논리적인 구조와 우선순위로 제시하는가 |
| 작업 분해 능력 | 복합적인 과업을 실행 가능한 하위 단계로 체계적으로 분해하는가 |
| 출력 설계 능력 | 결과물의 형식, 분량, 어조, 구성 및 예시를 명확히 지정하는가 |
| 상호작용 조율 능력 | AI의 응답을 바탕으로 핵심 방향을 신속하고 구체적으로 조정하는가 |
| 검증 유도 능력 | 오류 가능성, 반대 근거, 누락 요소 및 보완점을 점검하도록 요청하는가 |
| 실무 적용 능력 | 산출물이 실제 업무·학습 맥락에서 즉시 활용 가능한 수준으로 완성되었는가 |


**2. 진단 방식**

1. 사용자는 원하는 직무 시나리오를 선택합니다.
2. 서비스 내부에서 AI와 최대 5턴까지 대화합니다.
3. AI 응답과 별도로 산출물 영역이 대화에 따라 누적·수정됩니다.
4. AI가 수정 대상으로 명시한 산출물 구간만 기존 결과에 병합합니다.
5. 전체 대화 과정과 최종 산출물을 LLM Judge 평가 80%, 코드 기반 검사 20% 비중으로 평가합니다.

**3. 결과**

| 결과 유형 | 종합 점수 |
|---|---|
| 실전 위임형 | 85점 이상 |
| 구조화 활용형 | 70점 이상 85점 미만 |
| 기본 활용형 | 55점 이상 70점 미만 |
| 초안 의존형 | 55점 미만 |

- 100점 만점 종합 점수
- 8개 역량축별 점수와 평가 근거
- 가장 잘한 개입과 놓친 개입
- 강점과 약점 요약
- 가장 낮은 역량축을 기준으로 한 개선 제안
- 결과 저장 및 조회

## 6. 현재 상태

현재 저장소에는 다음 기능이 구현되어 있습니다.

- Track 1 전체 화면 흐름, 채점, 16가지 유형 결과 및 공유
- Track 2 전체 화면 흐름, 규칙 기반 채점, 피드백 및 결과 시각화
- Track 3 시나리오 선택, 인앱 채팅, 산출물 작성, 평가 및 결과 화면
- OpenAI 연동 및 API 키 미설정·오류 상황을 위한 fallback 처리
- Supabase 응시자 및 Track별 결과 저장
- 결과 이미지 생성 및 공유
- 사용자 행동 이벤트 수집
- Supabase 데이터를 BigQuery로 동기화하는 자동화 워크플로우
