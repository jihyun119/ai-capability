# AI 활용 유형/역량 진단 서비스 IA, 유저 플로우, 와이어프레임 카피

## 1. 서비스 정의

### 한 줄 정의
AI를 얼마나 쓰는지가 아니라, AI를 어떤 방식으로 다루는 사람인지 진단하는 AI 활용 습관 및 역량 테스트 서비스.

### 핵심 경험
유저는 가벼운 유형 테스트로 진입하고, 자신의 AI 사용 패턴을 확인한 뒤, 더 깊은 실전 역량 평가로 자연스럽게 이동한다.

### Track별 결과물 정의

| Track | 결과물 | 결과 성격 | 화면 표현 방식 |
| --- | --- | --- | --- |
| Track 1 | 유형화 | AI와의 관계/태도를 4축 기반 16개 캐릭터 유형으로 진단 | 캐릭터 결과 카드, 유형 설명, 공유 이미지 |
| Track 2 | 100점 만점 점수 | 실무 상황에서의 AI 활용 역량을 객관식 선택 기반으로 점수화 | 총점, 6개 역량 레이더 차트, 문항별 피드백 |
| Track 3 | 보고서/레포트 | 인앱 프롬프트 대화 로그를 분석해 실전 수행 과정과 개선 방향 제공 | 종합 리포트, CREATE 기준 평가, 개선 프롬프트 |

### 서비스 톤
- 재미있지만 가볍기만 하지 않음
- 취업/포트폴리오에 활용 가능한 근거 제공
- 평가받는 느낌보다 "내 AI 사용법을 발견하는 느낌"
- 2030이 공유하고 싶은 결과지 중심

## 3. 주요 유저 플로우

### Flow A. 첫 방문 유저 - Track 1 바이럴 진입

```text
랜딩 진입
→ "내 AI 관계 유형 알아보기" 클릭
→ Track 1 안내
→ 객관식 20문항 진행
→ AI 프롬프트 복사
→ 본인 AI에 붙여넣기
→ 나온 답변을 서비스에 붙여넣기
→ 분석
→ 결과 카드 확인
→ SNS 공유
→ Track 2 유도
```

### Flow B. 취준생 - Track 2 실용 진입

```text
랜딩 진입
→ "AI 활용 패턴 분석하기" 클릭
→ 평가 목적 안내
→ 전문 상황 문항 응답
→ 영문 미션 프롬프트 복사
→ 본인 AI 답변 붙여넣기
→ 활용 패턴 분석
→ 강점/약점/면접 표현 확인
→ Track 3 유도
```

### Flow C. 고관여 유저 - Track 3 실전 평가

```text
랜딩 진입
→ "실전 AI 역량 평가하기" 클릭
→ 직무 선택
→ 가상 시나리오 확인
→ 인앱 챗봇과 최소 3회 대화
→ 최종 평가 제출
→ CREATE 기준 채점
→ 0~100점/상위 퍼센트/개선 피드백 확인
→ 리포트 저장
```

## T1-02. 객관식 질문

### 화면 목적
20개 문항을 지루하지 않게 진행한다.

### 레이아웃
- 상단: 진행률 바, 현재 문항 번호
- 중앙: 질문 문장
- 하단: A~E 선택지 카드
- 우측/하단: 이전, 다음 버튼

### 주요 카피

**Progress**
3 / 20

**Question Example**
지원하는 회사에 제출할 자기소개서를 써야 합니다. AI를 어떻게 활용하시겠습니까?

**Option A**
"자기소개서 써줘"라고 바로 입력한다

**Option B**
지원 직무와 내 주요 경험을 알려주고 초안을 요청한다

**Option C**
초안을 받은 후 회사 분위기와 직무 키워드에 맞게 수정 요청을 반복한다

**Option D**
먼저 회사와 직무에서 원하는 인재상을 AI에게 물어보고, 그걸 기반으로 구성 방향을 잡는다

**Option E**
그때그때 다르다. 급하면 바로 쓰고, 여유 있으면 조금 더 구체화한다

**CTA**
다음

### Track 1 진단 구조

| 축 | 낮음 | 높음 |
| --- | --- | --- |
| 의존도 | AI 없어도 크게 불편하지 않음 | AI가 없으면 일상/작업에서 빈자리를 느낌 |
| 친밀도 | AI를 감정 없는 도구로 대함 | AI에게 정서적 친근감이나 대화감을 느낌 |
| 신뢰도 | AI 답변을 의심하고 검증함 | AI 답변을 대체로 신뢰하고 활용함 |
| 통제욕구 | AI에게 맡기고 결과를 받아들이는 편 | 방향, 조건, 수정 과정을 직접 주도하는 편 |

### Track 1 문항 방식

Track 1 파트 A는 MBTI식 5점 척도 문항으로 구성한다.

```text
A 문장  1 — 2 — 3 — 4 — 5  B 문장
1에 가까울수록 A 성향
5에 가까울수록 B 성향
3은 중간
```

### Track 1 문항 구성

| 축 | 문항 수 | 문항 번호 | 측정 내용 |
| --- | --- | --- | --- |
| 의존도 | 4문항 | Q1~Q4 | AI 사용 빈도, 생활 침투도, 신규 AI 탐색 성향 |
| 친밀도 | 4문항 | Q5~Q8 | 감정 표현, 고민 상담, 대화 과정의 즐거움 |
| 신뢰도 | 4문항 | Q9~Q12 | 답변 신뢰, 검증 습관, 판단 위임 정도 |
| 통제욕구 | 4문항 | Q13~Q16 | 조건 지정, 수정 요청, 대화 주도권, 중간 점검 |

### Track 1 채점 방식

```text
각 문항 1~5점
축별 4문항 합산 → 4~20점
중간값 12점 기준 고/저 판별

의존도: 12점 미만 → 저 / 12점 이상 → 고
친밀도: 12점 미만 → 저 / 12점 이상 → 고
신뢰도: 12점 미만 → 저 / 12점 이상 → 고
통제욕구: 12점 미만 → 저 / 12점 이상 → 고

4개 축의 고/저 조합 → 16개 유형 중 하나 배정
```

### 컬러 사용 원칙
- 전체 UI는 White와 Black을 기본으로 두고, Violet과 Lime은 행동 유도와 결과 화면의 에너지에 집중해서 사용한다.
- Track 1은 Lime을 더 많이 사용해 가볍고 바이럴한 인상을 준다.
- Track 2와 Track 3는 Violet 비중을 높여 진단/평가 서비스의 신뢰감을 만든다.
- 결과 공유 카드는 캐릭터 이미지가 중심이므로 배경은 단순하게 유지하고, 유형별 강조 컬러만 포인트로 사용한다.

### 결과 카드 레이아웃 반영

Track 1 결과 화면과 공유 카드에는 아래 순서를 적용한다.

1. 상단: 유형명 라벨
2. 중앙: 캐릭터 이미지
3. 하단: 한 줄 정의
4. 상세 영역: 강점, 주의점, 추천 AI 사용법
5. CTA: 결과 공유하기, Lv.1에서 더 분석하기

### 결과 공유 카드 카피 구조

```text
나는 [결과 유형]
[한 줄 정의]

AI 사용 강점
[강점 1문장]

주의할 점
[주의점 1문장]

내 AI 활용 패턴 더 보기
```

### Figma 에셋 배치 규칙
- 캐릭터 이미지는 원본 비율을 유지하고, 결과 카드 중앙에 220~280px 크기로 배치한다.
- 모바일 공유 카드에서는 캐릭터가 첫 화면의 40~45% 정도를 차지하게 한다.
- 캐릭터 이미지 위에 별도의 장식 요소를 많이 얹지 않는다.
- 유형 라벨은 캐릭터 이미지 안에 이미 포함되어 있으므로, 결과 화면의 텍스트 유형명과 중복되더라도 계층을 다르게 둔다.
- 공유 카드 배경은 White 또는 Black 중 하나로 단순하게 가고, Violet/Lime은 배지·라인·버튼에만 사용한다.

## 9. 디자인 방향

### 시각 톤
전문적인 진단 서비스처럼 신뢰감은 유지하되, 결과 공유 화면은 밈/테스트 콘텐츠처럼 가볍게 느껴지게 한다.

### 컬러 제안
- Base: Black / White
- Primary: Violet `#7D39EB`
- Accent: Lime `#C6FF33`
- Neutral: Cool Gray 계열을 보조로 사용
- Warning/Feedback: Amber, Red는 최소 사용

### 타이포그래피
- 헤드라인: 굵고 짧게
- 본문: 설명보다 행동 유도 중심
- 결과 화면: 유형명은 크고 강하게, 설명은 짧은 문단으로

### UI 원칙
- 랜딩은 설명보다 바로 테스트를 시작하게 만든다.
- Track 1은 카드형, 진행률, 공유 이미지 중심.
- Track 2는 리포트형 레이아웃으로 신뢰감 강화.
- Track 3는 실제 업무 도구처럼 좌측 시나리오 + 우측 대화 구조.
